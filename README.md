# Portable skill bundles

Original, MIT-licensed skill bundles that work across agent harnesses (Hermes Agent, OpenClaw, Codex, Goose, Cursor, Claude Code). Each skill follows the agentskills.io SKILL.md spec.

| Bundle | Purpose |
|---|---|
| site-health-check | Daily uptime and basic SEO check for your pages |
| meeting-actions | Notes or transcript to decisions, actions, owners, dates |
| weekly-topic-brief | Weekly sourced roundup on topics or competitors |
| first-touch-draft | Two short outreach drafts from facts you supply; never sends |

Each bundle folder has: `skills/<slug>/SKILL.md`, `memory.md`, `routines.yaml`, `mcp.json`, `goose-recipe.yaml`, `README.md` with install lines.
